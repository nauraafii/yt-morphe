# YTRVX Module

[![Build Status](https://github.com/nauraafii/ytrvx-module/actions/workflows/build.yml/badge.svg)](https://github.com/nauraafii/ytrvx-module/actions)
[![Latest Release](https://img.shields.io/github/v/release/nauraafii/ytrvx-module?label=Latest%20Release&color=blue)](https://github.com/nauraafii/ytrvx-module/releases/latest)

Proyek ini adalah fork yang disesuaikan untuk preferensi pribadi: pilihan patch, versi aplikasi, nama output, dan alur build. Repository ini membangun APK dan modul Magisk/KernelSU untuk YouTube dan YouTube Music menggunakan Morphe Patches.

## Rilis

Unduh file terbaru dari [Releases](https://github.com/nauraafii/ytrvx-module/releases). Modul ZIP dapat dipasang melalui Magisk atau KernelSU; APK non-root memerlukan GmsCore yang kompatibel untuk login Google.

## Catatan

- Konfigurasi build ada di [`config.toml`](config.toml).
- Ini bukan proyek resmi dari j-hc, Morphe, YouTube, atau Google.
- Kompatibilitas dapat berubah saat aplikasi atau patch diperbarui.
